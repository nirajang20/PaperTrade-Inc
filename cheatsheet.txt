=============================
 Git + MySQL SSH Tunnel Guide
=============================

VPS IP: 74.208.158.229
Repo Path: /var/repo/trade.git

--------------------------------------------
 SSH Tunnel for MySQL
--------------------------------------------
# Run this on your local machine to connect local port 3307 -> VPS MySQL (3306)
ssh -fN -L 3307:127.0.0.1:3306 root@74.208.158.229

# Then connect MySQL locally:
mysql -h 127.0.0.1 -P 3307 -u <dbuser> -p
